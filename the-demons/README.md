# THE DEMONS

A standalone browser game in `index.html`, `styles.css`, and `game.js`.

Open `index.html` in a browser to play. This is a human party moderator: every player is a real person, the app only deals roles, records votes, and resolves the night ally rule. The public board keeps every player looking like an ordinary masked guest.

The game is listed in the Awesome Delvelment launcher and requires an active 12-week Membership Pass stored by `rewards.html`.
